# Реальный корпус методичек

`methodical-guides/` содержит учебные материалы, используемые для
интеграционных evals навыка `lab-works`. Все файлы хранятся в Git намеренно.

## Правила использования

1. Метаданные и относительные пути находятся в `../corpus.json`; не дублируй
   номер лабораторной, тему или исходное имя файла в тестовых сценариях.
2. ASCII-имена файлов намеренны: они позволяют безопасно передавать путь
   внешним CLI-инструментам на Windows. Оригинальное имя сохранено в поле
   `source_filename` каталога.
3. Не редактируй оригинальные методички во время eval. Любые рабочие копии,
   XML, исходный код, отчёты, PNG и логи создавай только в изолированном
   `.skill-eval/workspace/iteration-*/.../outputs/`.
4. Перед использованием PDF проверь текстовый слой через
   `py scripts/pdf_text.py <path> <pages>`; DOCX — через
   `py scripts/docx_text.py <path>`.
5. Выводы о поведении навыка сохраняй в `EVAL_NOTES.md` с ссылкой на
   конкретные eval output и grading.json.

## Соглашение имён

- `lr-NN-<topic>.<ext>` — лабораторная работа с официальным номером.
- `pr-NN-<topic>.<ext>` — практическая работа.

Добавляя новую методичку, присвой ASCII-safe имя, внеси запись в
`evals/corpus.json` и добавь хотя бы один сценарий, который она расширяет.
